# 🧑‍💼 Employee Task Management System ( Frontend Only )

An intuitive and efficient web-based Employee Task Management System that helps organizations manage tasks and monitor employee progress. It includes secure login functionality and role-based access for **Admins** and **Employees**.

---

## 🚀 Features

- 🔐 **Login System**: Secure authentication for all users.
- 👨‍💼 **Admin Dashboard**:
  - Add, update, assign, or delete tasks.
  - Manage employee accounts.
  - View task progress and performance reports.
- 👷‍♂️ **Employee Dashboard**:
  - View assigned tasks.
  - Mark tasks as completed.
  - Track progress and deadlines.

---

## 🔑 User Roles

### 1. Admin
- Can create and manage employee profiles.
- Assign tasks with deadlines.
- Track overall task progress.
- Edit or delete tasks as needed.

### 2. Employee
- Can view only the tasks assigned to them.
- Update task status.
- Submit completed work for review.
